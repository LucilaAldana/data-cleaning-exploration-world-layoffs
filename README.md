# Data Cleaning & Exploratory Analysis of World Layoffs in MySQL

## by Lucila Aldana Quiñonez | Marketing Data Analyst

This project focuses on cleaning and exploring a real-world dataset of global layoffs using MySQL to ensure data integrity, consistency, and analytical readiness.

The objective was to transform raw, inconsistent layoff records into a structured and reliable dataset through systematic data cleaning and exploratory SQL analysis.

The project includes:

• Duplicate detection and removal using window functions

• Standardization of company names, industries, and country fields

• Date format conversion and normalization

• Handling of null and missing values

• Data type corrections and schema adjustments

• Validation checks to ensure dataset consistency

After cleaning, exploratory analysis was performed to examine:

• Total layoffs by company and industry

• Layoffs by country and region

• Yearly and monthly layoff trends

• Companies with the highest workforce reductions

• Percentage-based layoffs and full company shutdown cases

Key insights supported by the analysis include identifying industries most affected by layoffs, detecting temporal patterns during economic downturns, and evaluating geographic concentration of workforce reductions.

This project simulates a real-world data preparation workflow where raw operational data must be cleaned, validated, and structured before being used for business intelligence or decision-making.

Tools Used: MySQL / SQL Window Functions / Data Cleaning / Exploratory Data Analysis / Data Validation / Generative AI
